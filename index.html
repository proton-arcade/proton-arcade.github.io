About This Arcade

ROM Arcade is a retro-gaming front-end built on EmulatorJS v4.2.3 — an open-source (GPL-3.0) RetroArch front-end for the web. Emulation cores load from the local data/cores/ folder and automatically fall back to the official EmulatorJS CDN for systems that aren’t bundled.

We are not responsible for anything. This site ships with no commercial ROMs. All games remain the property of their original creators. Only play games you legally own or that are freely distributed. This project was created with the assistance of AI — for personal use only.
